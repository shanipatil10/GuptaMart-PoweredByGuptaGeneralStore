# Gupta General Store – Project Requirements Document

## 1. Project Goal
Build a real-world grocery store website for Gupta General Store that customers can actually use to browse products and place Cash on Delivery orders.

## 2. Target Users
- Local grocery customers
- Shop owner (admin)

## 3. Tech Stack
- Next.js
- Tailwind CSS
- Node.js
- Express.js
- MySQL
- Firebase Authentication

## 4. Pages
- Home
- Categories
- Product Details
- Cart
- Checkout
- Login
- Signup
- Profile
- About
- Contact
- Admin Dashboard

## 5. Payment
Cash on Delivery only.

## 6. Features
- Login/Signup
- Search
- Categories
- Add to Cart
- Place Order
- Admin Order Management
- Product Management

## 7. Out of Scope
- Online payments
- Coupons
- Wallet
- AI chatbot
- Delivery tracking
- Reviews
